# FileChannel · 文件通道

两台电脑之间的**点对点文件通道**：各开一个窗口，把文件／文件夹拖进去就发过去，对面弹窗可以选择**接受 / 拒绝**。
不需要中转服务器，局域网 / Radmin VPN / Tailscale 都可用。

- 程序（绿色免安装，Windows x64，目标电脑不需要装 Python）：[`FileChannel.exe`](FileChannel.exe)
- 双击启动：[`启动文件通道.cmd`](启动文件通道.cmd)
- 首次使用先放行端口：[`安装防火墙规则(以管理员运行).cmd`](安装防火墙规则(以管理员运行).cmd)（右键 → 以管理员身份运行）
- 详细说明（两台机器怎么连通 / 怎么用 / 排错）：[`使用说明.md`](使用说明.md)

用法：两台机器各双击 `启动文件通道.cmd` → 把对方的「本机地址」填到“对方地址”里 → 点**测试连接**变成绿色 → 把文件**拖进蓝色区域**发送。
